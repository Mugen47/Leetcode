# 🧭 Recommended Learning Order

> [!IMPORTANT]
> Algorithmic learning is a Directed Acyclic Graph (DAG). Learning topics out of order causes rote memorization because the underlying logical foundation is missing.

<details open>
<summary><b>Phase 1: Foundations & Sequence Control</b></summary>
*Concrete, linear data structures. Easy to visualize.*

- Arrays & Strings Fundamentals
- Two Pointers (Opposite Direction, Same Direction, Fast/Slow)
- Cyclic Sort & Dutch National Flag
</details>

<details open>
<summary><b>Phase 2: Windows & Precomputations</b></summary>
*Optimizing O(N²) traversal into O(N) by maintaining state.*

- Sliding Window (Fixed, Variable)
- Prefix Sum & Prefix Information
- Difference Arrays (1D Range Updates)
</details>

<details open>
<summary><b>Phase 3: Fast Lookups & Frequencies</b></summary>
*Trading space for time. Introduction to Hashing.*

- Hashing (Frequency Counting, Grouping)
- Subarray Hashing (Prefix Sum + HashMap)
</details>

<details open>
<summary><b>Phase 4: Search Space Reduction</b></summary>
*Dividing search spaces logarithmically.*

- Binary Search (Standard, Lower/Upper Bound)
- Binary Search on Answer (Parametric Search)
</details>

<details open>
<summary><b>Phase 5: Linear Structures & Monotonicity</b></summary>
*Maintaining order dynamically.*

- Linked Lists
- Stacks & Queues
- Monotonic Stack & Monotonic Queue
</details>

<details open>
<summary><b>Phase 6: Search, Enumeration, & Geometry</b></summary>
*Exhaustive search and geometric event processing.*

- Recursion & Backtracking (Subsets, Permutations, Combinations)
- Sorting, Intervals (Merge, Overlap)
- Sweep Line
</details>

<details open>
<summary><b>Phase 7: Trees & Hierarchies</b></summary>
*Non-linear structures. Crucial for Graphs and DP.*

- Tree Traversals (DFS / BFS)
- Structural Properties (LCA, Subtrees, BSTs)
- Tries (Prefix Trees)
</details>

<details open>
<summary><b>Phase 8: Graph Theory</b></summary>
*Complex connectivity and state transitions.*

- Graph Fundamentals (Representations, Traversals)
- Topological Sort (Kahn's Algorithm)
- Union Find / DSU
- Shortest Paths (Dijkstra) & Minimum Spanning Trees
</details>

<details open>
<summary><b>Phase 9: State Optimization (DP & Greedy)</b></summary>
*Finding optimal substructures.*

- Dynamic Programming (1D, 2D, Knapsack, Bitmask)
- Greedy Algorithms (Sorting + Greedy, Exchange Arguments)
</details>

<details open>
<summary><b>Phase 10: Advanced Specialized Patterns</b></summary>
*Advanced optimizations and highly specific data structures.*

- Heaps / Priority Queues
- Bit Manipulation
- String Algorithms (Rolling Hash, KMP, Z-Algo)
- Advanced Range Queries (Segment Trees, Fenwick Trees)
- Mathematics & Geometry
</details>
